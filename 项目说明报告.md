## 1. 项目概述

### 1.1 项目简介
ZuPu 是一个基于 Spring Boot 的族谱管理系统，用于管理家族树、人物信息、家族事件、留言板等功能。

### 1.2 核心功能
- 用户认证与授权（登录/注册）
- 家族管理（创建、编辑、删除家族）
- 人物管理（添加、编辑家族成员）
- 家族树可视化展示
- 留言板（支持富文本、分页、文件上传）
- 数据导入导出（Excel 格式）
- 文件上传下载
- AI 智能助手

### 9.2 分页显示功能

#### 9.2.1 实现方式
采用**手动分页**实现，不使用 PageHelper：

1. **计算偏移量**
2. **SQL 分页查询**
3. **计算总页数**
4. **返回分页数据**

#### 9.2.2 Controller 实现
[MessageBoardController.java](file:///f:/C++试错/ZuPu/src/main/java/com/zupu/zupu/controller/MessageBoardController.java#L44-L86)
```java
@GetMapping
public String list(@RequestParam(defaultValue = "1") int pageNum,
                   @RequestParam(defaultValue = "3") int pageSize,
                   Model model) {
    // 1. 计算偏移量
    int offset = (pageNum - 1) * pageSize;
    
    // 2. 查询数据
    List<MessageBoard> messages = messageBoardService.listByPage(offset, pageSize);
    int total = messageBoardService.count();
    
    // 3. 计算总页数
    int pages = (int) Math.ceil((double) total / pageSize);
    
    // 4. 组装分页信息
    Map<String, Object> pageInfo = new HashMap<>();
    pageInfo.put("total", total);
    pageInfo.put("pageNum", pageNum);
    pageInfo.put("pages", pages);
    pageInfo.put("hasPreviousPage", pageNum > 1);
    pageInfo.put("hasNextPage", pageNum < pages);
    
    model.addAttribute("messages", messages);
    model.addAttribute("pageInfo", pageInfo);
    return "message/index";
}
```

### 9.4 文件上传下载功能

#### 9.4.1 文件上传
[FileController.java](file:///f:/C++试错/ZuPu/src/main/java/com/zupu/zupu/controller/FileController.java#L39-L89)

**流程**：
1. 接收 MultipartFile
2. 按日期创建目录（`uploads/yyyy/MM/dd/`）
3. 生成 UUID 文件名
4. 保存文件
5. 返回文件 URL

```java
@PostMapping("/upload")
public Map<String, Object> upload(@RequestParam("file") MultipartFile file) {
    // 创建日期目录
    String datePath = LocalDate.now().format(DateTimeFormatter.ofPattern("yyyy/MM/dd"));
    Path uploadDir = Paths.get(uploadPath, datePath);
    Files.createDirectories(uploadDir);
    
    // 生成 UUID 文件名
    String originalFilename = file.getOriginalFilename();
    String extension = "";
    if (originalFilename != null && originalFilename.contains(".")) {
        extension = originalFilename.substring(originalFilename.lastIndexOf("."));
    }
    String newFilename = UUID.randomUUID().toString() + extension;
    
    // 保存文件
    Path filePath = uploadDir.resolve(newFilename);
    Files.copy(file.getInputStream(), filePath, StandardCopyOption.REPLACE_EXISTING);
    
    // 返回结果
    Map<String, Object> result = new HashMap<>();
    result.put("success", true);
```

```java
@GetMapping("/download/**")
public ResponseEntity<Resource> download(HttpServletRequest request,
                                          @RequestParam(required = false) String originalFilename) {
    // 提取文件路径
    String uri = request.getRequestURI();
    String filePath = uri.replace("/api/file/download/", "");
    
    // 读取文件
    Path file = Paths.get(uploadPath, filePath);
    Resource resource = new UrlResource(file.toUri());
    
    // 返回文件响应
    String downloadFilename = originalFilename != null ? originalFilename : file.getFileName().toString();
    String encodedFilename = URLEncoder.encode(downloadFilename, StandardCharsets.UTF_8);
    
    return ResponseEntity.ok()
        .contentType(MediaType.APPLICATION_OCTET_STREAM)
        .header(HttpHeaders.CONTENT_DISPOSITION, "attachment; filename=\"" + encodedFilename + "\"")
        .body(resource);
}
```

```java
        cell.setCellStyle(createHeaderStyle(workbook));

        row.createCell(2).setCellValue(family.getAncestorName());
```
